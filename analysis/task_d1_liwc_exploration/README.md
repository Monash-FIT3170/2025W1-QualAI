# Task D.1: LIWC Dataset Exploration for Faculty & Sex Differences

## Overview

This analysis explores Linguistic Inquiry and Word Count (LIWC) datasets from Monash University Moodle forums to investigate differences in linguistic patterns between different faculties and sexes. The analysis uses the LIWC2015 framework to examine ~90 linguistic and psychological variables.

You need two CSV files:
1. `forum_ind_train.csv` - Contains independent variables including:

Place these files in the `data/` subdirectory.

## LIWC2015 Framework

The analysis examines variables from the LIWC2015 framework, organized into categories:

### Summary Variables
- **Analytic** - Analytical thinking
- **Clout** - Social status, confidence
- **Authentic** - Authenticity
- **Tone** - Emotional tone (positivity)

### Linguistic Dimensions
- Word count, words per sentence, dictionary words
- Function words (articles, prepositions, etc.)
- Pronouns (personal, impersonal)
- Verbs, adjectives, comparisons, interrogatives, numbers, quantifiers

### Psychological Constructs
- **Affective processes**: Positive/negative emotion, anxiety, anger, sadness
- **Social processes**: Family, friends, male, female
- **Cognitive processes**: Insight, causation, discrepancy, tentativeness, certainty, differentiation
- **Perceptual processes**: See, hear, feel
- **Biological processes**: Body, health, sexual, ingest
- **Drives**: Affiliation, achievement, power, reward, risk
- **Time orientation**: Focus past, present, future
- **Relativity**: Motion, space, time
- **Personal concerns**: Work, leisure, home, money, religion, death

## Statistical Methods

### Faculty Differences (ANOVA)
- One-way ANOVA for each LIWC variable
- Effect size: Eta-squared (η²)
- Multiple comparison correction: Bonferroni method

### Sex Differences (T-tests)
- Independent samples t-tests for each LIWC variable
- Effect size: Cohen's d
- Multiple comparison correction: Bonferroni method

### Effect Size Interpretation

**Cohen's d:**
- Small: 0.2
- Medium: 0.5
- Large: 0.8

**Eta-squared (η²):**
- Small: 0.01
- Medium: 0.06
- Large: 0.14

## Interpretation Guidelines

1. **Multiple Testing**: Use Bonferroni-adjusted p-values for formal conclusions to control for false positives

2. **Effect Sizes**: Consider both statistical significance and practical significance (effect size)

3. **Context**: Interpret findings in relation to:
   - Educational contexts (different faculties have different discourse patterns)
   - Gender communication research
   - LIWC2015 validation studies and psychological theory

4. **Post-hoc Analysis**: For significant ANOVA results, conduct post-hoc tests (e.g., Tukey HSD) to identify which faculty pairs differ

## Example Results Interpretation

### Significant Faculty Differences
If ANOVA shows significant differences in "Analytic" thinking:
- Higher scores indicate more formal, logical, and hierarchical thinking
- Lower scores indicate more narrative, personal, and dynamic thinking
- Consider how different academic disciplines (STEM vs. humanities) might influence writing style

### Significant Sex Differences
If t-tests show significant differences in "Social processes":
- Examine whether one group uses more social reference words
- Consider gender communication research literature
- Be cautious about overgeneralizing - within-group variation is often larger than between-group differences
